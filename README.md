# WilliamOS — williamdev.is-a.dev

Williamjeet Singh's portfolio: a newsprint "Ink OS" desktop built with Astro. Every window is a real page.

```
npm install
npm run dev        # local dev server
npm test           # unit tests (vitest)
npm run e2e        # browser tests (playwright; builds + previews first)
npm run build      # static site in dist/
```
